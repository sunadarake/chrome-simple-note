# 何も書かずに閉じた新規メモを保存しない

## 概要
「新しいメモ」「シークレットメモ」を押しただけで何も書かずにタブを閉じた（またはリロードした）とき、空のメモが `localStorage` / `sessionStorage` に残らないようにする。「何も書いていない」は、空文字と空白文字（スペース・改行・タブなど）だけの内容をいう（`content.trim() === ''`）。

## 調査結果
- `src/memo.js` の `createNewMemo` が、メモを作ってすぐ `saveMemos` で保存している。このため空のメモが保存先に残り、リロードすると「無題のメモ」が一覧に出る。
- `persistCurrentContent`（自動保存・保存ボタン）、`deleteMemo`、`importFromFile` も `saveMemos` に `memos` 全体を渡すので、メモリ上の空メモがあると、そのとき一緒に保存先に書かれてしまう。
- 自動保存は、空白のみなら `persistCurrentContent` を呼ばない（`handleContentInput`）。保存ボタン（`saveMemo`）には空白チェックがない。
- `src/storage.js` の `saveMemos` は、`secret` で local と session に振り分けて書くだけ。
- `src/memo.test.js` に「空白のみの内容は自動保存しない」「新しいメモ」ボタンのテストがある。

## 実装計画
- [x] ステップ1: `saveMemos` で、`content.trim() === ''` のメモを書き込み対象から外す。メモリ上の `memos` は変えないので、一覧には「無題のメモ」として出続ける（`src/storage.js`）
- [x] ステップ2: `createNewMemo` から `saveMemos` の呼び出しを外す（ステップ1で空メモは書かれないため、不要な書き込みになる）（`src/memo.js`）
- [x] ステップ3: 保存ボタンで空白のみのときの扱いをそろえる。`saveMemo` が空白のみの内容を `persistCurrentContent` で `memos` に反映してしまうと、保存済みメモがリロードで消えるため、空白のみなら反映しない（ログの文言は実装時に決める）（`src/memo.js`）
- [x] ステップ4: テストを追加する。(a) `saveMemos` が空・空白のみのメモを書かない（通常・シークレット両方）(b) 「新しいメモ」を押して何も書かない状態では `localStorage` / `sessionStorage` に空メモが入らない (c) 空白だけを入力して1秒待っても保存されない (d) 文章を書くと保存され、リロード相当（`initMemoApp` の再実行）で残る (e) 空メモがある状態で別メモを削除しても、空メモは書かれない（`src/storage.test.js`、`src/memo.test.js`）
- [x] ステップ5: `AGENTS.md` の仕様に、「空（空白のみを含む）の新規メモは保存先に書かない。一覧には出るが、タブを閉じるとなくなる」を 1 行で追記する（`AGENTS.md`）

## テスト・確認方法
- [x] `npm test` / `npm run lint` / `npm run typecheck` / `npx prettier --check .` が通ること
- [ ] 実機で、「新しいメモ」を押して何も書かずにリロードすると、空のメモが増えないこと
- [ ] 実機で、スペースや改行だけ入力してリロードしても残らないこと
- [ ] 実機で、文章を書いて1秒待つ（または保存ボタン）とリロード後も残ること
- [ ] 実機で、シークレットメモでも同様であること

## 決定事項
- 「閉じる」は、タブを閉じる／リロードを指す。別のメモを選んだとき、もう一度「新しいメモ」を押したときの特別な破棄はしない（メモリ上に残り、一覧にも出る）。
- 空の新規メモは、書き始める前も一覧に「無題のメモ」として表示する（現状どおり）。
- 保存済みメモの本文を全部消して空白だけにした場合は、今までどおり保存しない（前回保存した内容が残る）。

- 保存ボタンを空白のみで押したときは「内容が空のため保存しませんでした」を灰色のログで出す。

## 懸念点・未決事項
- すでに保存先に残っている空メモは、この変更では消えない。次に何かを保存すると `saveMemos` のフィルターで消える（一括の掃除処理は作らない）。問題なければこのままとする。
- 保存先に書く対象を `saveMemos` で絞るため、保存済みメモが空白のみになった状態で保存ボタンを押すと、ステップ3の扱い次第でログ表示が変わる。実装前に文言を決める。
- 空のメモに触れず別のメモを選んでも、その空メモは一覧に残ったまま（リロードで消える）。「別のメモを選んだら消す」にしたい場合は別途検討する。
