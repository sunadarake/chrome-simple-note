# キーボードショートカットを VSCode/vim 向けに拡充する

## 概要
現在の Ctrl+U（アンドゥ）を Ctrl+Z に変え、リドゥ（Ctrl+Shift+Z）、検索欄へのフォーカス（Ctrl+F / Ctrl+P）、パネルやタイトル編集を閉じる Esc、設定を開く Ctrl+,、前後のメモ移動（Ctrl+J / Ctrl+K）を追加する。操作感を VSCode / vim 利用者に合わせる。

## 調査結果
- `src/shortcuts.js` に `SHORTCUTS`（ヘルプ表示）と `initShortcuts` の keydown 処理がまとまっている。Ctrl+C / Ctrl+S / Ctrl+U / Ctrl+O / Ctrl+Shift+O / Delete を扱う。
- `src/memo.js:108` 付近にアンドゥ履歴 `undoHistory` / `undoValue` がある。`undoContent` は `src/memo.js:311`。リドゥは無い。履歴はメモを開くたびに空にする。
- 検索欄は `.search-input`。`filterMemos`（`src/memo-store.js`）がタイトルと本文を対象に絞り込む。Ctrl+P はこの検索欄へフォーカスする（本文も対象）。
- メモ一覧の並びは `memos` 配列の順（新しい順）。`filterMemos` の結果が見えている一覧と一致する。
- 設定・ヘルプを開くと `editor.hidden` が true になり、`isActive` が false になる。Esc だけはパネルを閉じるため isActive に関係なく効かせる必要がある。
- タイトル入力の Escape は `src/memo.js:562` 付近の titleInput の listener が処理している（コンテナへは bubble しないテストもある）。
- ヘルプの一覧は `SHORTCUTS` から描画され、テストでキー配列を検証している（`src/shortcuts.test.js:37`, `src/memo.test.js` のヘルプ節）。
- README.md と AGENTS.md にもショートカット一覧の記述がある。

## 決定事項
- Ctrl+U は廃止し、アンドゥは Ctrl+Z にする。
- リドゥは Ctrl+Shift+Z。
- Ctrl+P は既存の検索欄へフォーカスする（タイトルだけでなく本文も検索対象）。
- Ctrl+J / Ctrl+K は検索で絞り込んだ一覧の中を移動し、端では止まる（ループしない）。
- Esc は設定・ヘルプ・タイトル編集・検索欄から本文へ戻る。パネルを開いている間も効く。
- Delete（メモ削除）は今回変更しない。

## 懸念点・未決事項
- Ctrl+F と Ctrl+P はどちらも検索欄へフォーカスするため、挙動は同じ（ヘルプでは説明文だけ変える）。将来 Ctrl+F を本文内検索に変える余地がある。
