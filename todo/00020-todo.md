# メイン画面の左右の余白を広げる

## 概要
メイン画面（タイトル行とエディタ）が左右の端に近いので、左右の余白を 6px から 11px（5px 足す）にして、少しゆとりを持たせる。

## 調査結果
- `src/memo.css` の `.main-content`（160〜169行付近）が `padding: 30px 6px 6px;` で、左右 6px。上の 30px はログとシークレットのラベルを重ねる場所なので触らない。
- タイトル行（`.main-header`）とエディタ（`.editor`）はどちらも `.main-content` の内側にあるので、ここを変えれば両方そろって動く。
- `.log-message` と `.secret-label` は絶対配置で上余白に重ねている。左右の位置の指定（`left` / `right`）が `.main-content` の padding に依存していないか確認が必要。
- 設定パネル（`.settings-panel`）も `.main-content` の中にあるため、同じ余白の影響を受ける。

## 実装計画
- [x] ステップ1: `src/memo.css` の `.main-content` を `padding: 30px 11px 6px;` にする
- [x] ステップ2: `.log-message` / `.secret-label` / `.sidebar-open` など `.main-content` 基準で絶対配置している要素の左右の指定を確認し、余白が変わっても位置が不自然にならないようにする（必要なら直す）
- [x] ステップ3: `AGENTS.md` に余白の記載があれば更新する（現状は「上余白（30px）」の記述のみ）

## テスト・確認方法
- [x] `npm test` / `npm run lint` / `npm run typecheck` / `npx prettier --check .` が通ること
- [x] 実機で、タイトル行とエディタの左右に余白が広がり、サイドバーを開閉しても崩れないこと
- [x] 実機で、設定パネル・ログ表示・シークレットのラベルの位置が不自然でないこと（通常・ダーク・シークレット）

## 決定事項
- 余白はメイン画面全体（`.main-content`）に足す。タイトル行もエディタも対象
- 値は 6px → 11px（5px 足す）

## 懸念点・未決事項
- `.secret-label` と `.log-message` は左右いっぱいの帯で、文字の左右の余白が 6px だったため、本文とそろうよう 11px にした（ステップ2）
- AGENTS.md には左右の余白の記載がなく、更新は不要だった
- 設定パネルの余白も広がる。問題なければそのままにする
