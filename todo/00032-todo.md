# Ctrl+O / Ctrl+Shift+O でメモを作成するショートカット

## 概要
メモ画面で Ctrl+O を押すと通常メモ、Ctrl+Shift+O を押すとシークレットメモを新規作成できるようにする。マウスで「新しいメモ」「シークレットメモ」ボタンを押したときと同じ動作にし、Chrome の既定動作（ファイルを開く／ブックマークマネージャー）は `preventDefault()` で止める。ヘルプのショートカット一覧にも追加する。

## 調査結果
- `src/shortcuts.js`: `SHORTCUTS` にヘルプ表示用の一覧、`initShortcuts` に `keydown` の判定がある。現在は Ctrl+C / Ctrl+S / Ctrl+U / Delete のみ。`withCtrl` は Alt・Meta のみ除外しており Shift は許可している。
- `src/memo.js`: `createNewMemo(secret)` が新規メモ作成の本体。`initShortcuts` には `copy` / `save` / `undo` / `remove` を渡している。`isActive` はエディタ表示中のみ true（設定・ヘルプパネル表示中は無効）。
- `src/shortcuts.test.js`: deps とヘルプ一覧（4キー）を検証している。
- `src/memo.test.js`: ヘルプのショートカット一覧（4キー）を検証している。
- `AGENTS.md`・`README.md`: ショートカット一覧の記載がある。

## 決定事項
- 既存の「新しいメモ」「シークレットメモ」ボタンと同じ動作にする（未保存内容の確認や自動保存は行わない）。
- ショートカットは既存と同じく、エディタ表示中のみ有効（設定・ヘルプパネル表示中は無効）。

## 懸念点・未決事項
- Ctrl+Shift+O は Chrome のブックマークマネージャーと競合する可能性がある。`preventDefault()` で止める方針だが、ブラウザ側が先に処理する場合は効かないことがある。
