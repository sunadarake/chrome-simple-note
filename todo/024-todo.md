# 設定ボタン（`.settings-btn`）のアイコンを3本線にする

## 概要
サイドバーのヘッダー左端にある設定ボタンのアイコンを、歯車（⚙）から3本線（☰）に変える。

## 調査結果
- アイコンは `src/memo.html` の `.settings-btn` の中に文字 `⚙` として直接書かれている（画像ではない）。
- `src/memo.css` の `.settings-btn` は文字色・フォントサイズ（18px）・余白だけを指定していて、アイコンの形には依存しない。
- `src/memo.test.js` は `.settings-btn` をクリックして開閉を確かめるだけで、アイコンの文字は見ていない。
- `AGENTS.md` の設定の説明に「歯車（`.settings-btn`）」とある。

## 実装計画
- [x] ステップ1: `src/memo.html` の `.settings-btn` の中身を `⚙` から `☰` に変える（`src/memo.html`）
- [x] ステップ2: `AGENTS.md` の「歯車（`.settings-btn`）」「歯車で戻る」を、3本線の表現に直す（`AGENTS.md`）
- [x] ステップ3（追加）: `README.md` の「歯車」2か所も3本線に直す（`README.md`）

## テスト・確認方法
- [x] `npm test` / `npm run lint` / `npm run typecheck` / `npx prettier --check .` が通ること
- [ ] 実機で、サイドバー左上のアイコンが3本線で表示され、押すと設定パネルが開閉すること（ライト・ダーク・シークレットで見た目が崩れないこと）

## 決定事項
- 3本線は文字の `☰`（U+2630）にする。画像やSVGは使わず、既存と同じ文字のアイコンにする

## 懸念点・未決事項
- `☰` は環境のフォントによって線の太さや大きさが少し違う。実機で見て、18px で他のボタン（`«`）とつり合わなければ報告する
- 調査で `README.md` にも「歯車」の記述が2か所あると分かり、ステップ3として追加した
