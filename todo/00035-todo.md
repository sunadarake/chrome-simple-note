# 設定・ヘルプをシークレットメモの配色から切り離す

## 概要
シークレットメモを開いているときに設定またはヘルプを開くと、パネルとその周囲の余白まで暗い背景になり、文字色もシークレット用の明るい色に変わってしまう。設定・ヘルプはシークレットメモの配色の影響を受けず、通常のライト配色で表示する。上部の「シークレットメモ」ラベルは表示したままにする。

## 調査結果
- `.main-content.secret` がメイン画面全体の背景を `#2b2d31` にしている（`src/memo.css:564`）。
- `.settings-panel` / `.help-panel` は背景色を持たず、`.main-content` の背景が透けて見える（`src/memo.css:246`）。
- シークレット時の設定・ヘルプ用に、`.main-content.secret .settings-*` / `.shortcut-*` / `.help-version` / 各ボタン / `select` / `.settings-panel.drop-active` の配色上書きがまとまっている（`src/memo.css:884` 以降）。
- パネルの開閉は `setSettingsOpen` / `setHelpOpen` が行い、`syncMainVisibility` がタイトル行とエディタを隠す（`src/memo.js:377`、`src/memo.js:387`、`src/memo.js:398`）。
- `.secret-label` は絶対配置で上余白に重なっており、パネルを開いても表示状態は変わらない（`src/memo.css:551`）。

## 実装計画
- [x] ステップ1: `src/memo.js` の `syncMainVisibility` で、パネルが開いているかどうかを `.main-content` の `panel-open` クラスに反映する（`src/memo.js:377`）。
- [x] ステップ2: `src/memo.css` の `.main-content.secret` の近くに `.main-content.secret.panel-open { background: #ffffff; }` を追加し、設定・ヘルプを開いている間は余白を含めて白背景にする（`src/memo.css:564`）。
- [x] ステップ3: `src/memo.css:884` 以降から、`.main-content.secret` 向けの設定・ヘルプの配色上書き（`.settings-header` / `.settings-section` / `.settings-title` / `h2` / `.settings-kind-title` / `.shortcut-row` / `.shortcut-keys` / `.shortcut-description` / `.help-version` / `.settings-close-btn` / `.export-btn` / `.import-btn` / `.save-settings-btn` / `.reset-settings-btn` / `.settings-panel select` / 各ホバー / `.delete-all-btn:hover` / `select option` / `.settings-panel.drop-active`）を削除する。`.container[data-theme='dark']` 向けのルールは TODO 00036 で消すため残す。
- [x] ステップ4: 削除後に、設定・ヘルプの各要素が既定のライト配色（枠線 `#eee`、見出し `#666`、補助文字 `#999`、ボタン `#333`、ドロップ中の枠 `#999` と薄い背景）で表示されることを確認する（`src/memo.css`）。
- [x] ステップ5: `.secret-label` と `.main-content.secret` のエディタ用配色は変更しない（`src/memo.css:551` 以降）。

- [x] 実機で、シークレットメモを開いたままヘルプを開いても同様にライト配色になることを確認する。

- [x] 実機で、通常メモ・シークレットメモのエディタ配色が変わっていないことを確認する。

## 決定事項
- シークレットメモ中でも、設定パネルとその周囲の余白は通常のライト配色に戻す。
- ヘルプパネルも設定パネルと同様に、シークレットメモの暗い配色から切り離してライト配色にする。
- 上部の「シークレットメモ」ラベルは、設定・ヘルプを開いている間も表示したままにする。

## 懸念点・未決事項
- `src/memo.css:884` 以降は `.container[data-theme='dark']` と `.main-content.secret` のセレクタが同じルールに並んでいる。TODO 00036（ダークモード廃止）と同じ箇所を触るため、この TODO を先に完了し、シークレット用セレクタを外してからダーク用セレクタを消す。
- `panel-open` はシークレット時だけ背景を変える用途に限定する。通常メモでは見た目が変わらないようにする。
- jsdom では実際の配色を検証できないため、色の確認は実機で行う。
