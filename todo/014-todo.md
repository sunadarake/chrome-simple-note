# デザインをミニマリスト寄りにする

## 概要
装飾（グラデーション、影、浮き上がるホバー、強い色）を減らし、白・グレー中心の落ち着いた見た目にする。色は文字と細い線、青のアクセント（選択中のメモ・フォーカス）に絞る。見た目だけの変更で、構造と挙動は変えない。

## 調査結果
対象は `src/memo.css` が中心。`src/memo.html` / `src/memo.js` はクラス名を保てば変更不要。
- `body`: 背景が青系のグラデーション。`.container`: 外側に影。
- `.sidebar`: 紺のグラデーション背景、右に影、文字は白。`.sidebar-title` に文字影。
- `.new-memo-btn` / `.secret-memo-btn`: 青／グレーのグラデーション、影、ホバーで `translateY(-2px)`。
- `.search-input`: 半透明の白背景、内側に影。
- `.memo-item`: 半透明の白背景、ホバーで `translateX(3px)`、選択中は青の背景と左線。
- `.export-btn` / `.import-btn` / `.sidebar-menu` / `.sidebar-menu-btn` / `.sidebar-close`: 白の半透明（暗い背景前提）。メニューには影。
- `.delete-btn`（赤）/ `.copy-btn`（紫）/ `.save-btn`（緑）: グラデーション、影、ホバーで浮く。
- `.editor`: 内側の影、フォーカスで青い枠線。`.log-message`: 薄い青の背景。
- スクロールバー: 背景 `#f1f1f1`、つまみ `#bdc3c7`。
- シークレット用の配色は `.main-content.secret` 配下と `.memo-item.secret` に分かれている（ダーク）。
- テストは見た目に依存しない。サイドバー幅のドラッグ（`.sidebar-resizer`）の動作にも影響しない。

## 実装計画
- [x] ステップ1: 全体。`body` を白に近い単色（例 `#fff`）にし、`.container` の影を外す。ホバーの `translate` による動きと、`transition: all` を見直して、色だけの変化にする（`src/memo.css`）
- [x] ステップ2: サイドバーを明るい単色にする（例 背景 `#fafafa`、右に 1px の細い線、文字は濃いグレー）。`.sidebar` の影、`.sidebar-title` の文字影を外す。タイトルは太さを抑える（`src/memo.css`）
- [x] ステップ3: 「新しいメモ」「シークレットメモ」ボタンを、背景なし／薄いグレーの枠線ボタンにする。グラデーション・影・浮き上がりを外す。`.search-input` は下線または細い枠線だけにする（`src/memo.css`）
- [x] ステップ4: メモ一覧。`.memo-item` の背景を透明にし、ホバーは薄いグレー、選択中は薄いグレー＋左に細い青線にする。ホバーの `translateX(3px)` をやめる（`.memo-list` の `overflow-x: hidden` は残す）。`.memo-item.secret` の配色を明るいサイドバー用に直す（`src/memo.css`）
- [x] ステップ5: サイドバー内の「☰」「«」「エクスポート」「インポート」とメニューを、明るい背景用の色（枠線のみ・濃いグレー文字）に直す。メニューの影は細い枠線に替える（`src/memo.css`）
- [x] ステップ6: 削除・コピー・保存ボタンを、背景なしの細い枠線ボタンにそろえる。ホバーは薄いグレー。削除だけホバー時に赤い文字にする。影・グラデーション・浮き上がりを外す（`src/memo.css`）
- [x] ステップ7: タイトル・エディタ・ログ。タイトルは太さと大きさを少し抑える。`.editor` の内側の影を外し、枠線は細いグレー、フォーカス時は青（または濃いグレー）。ログは背景なしの控えめなグレー文字、または薄いグレーの背景にする。スクロールバーは細く目立たない色にする（`src/memo.css`）
- [x] ステップ8: シークレット配色（`.main-content.secret` 配下、`.memo-item.secret`）はダークのまま、影・グラデーション・色の主張を減らして上の変更とそろえる（`src/memo.css`）
- [x] ステップ9: `AGENTS.md` に、デザイン方針（影・グラデーション・浮き上がりを使わない、色は青のアクセントだけ）を 1 行で追記する。シークレットの記述のうち、サイドバーの色に触れているところがあれば直す（`AGENTS.md`）

## テスト・確認方法
- [x] `npm test` / `npm run lint` / `npm run typecheck` / `npx prettier --check .` が通ること
- [ ] 実機で、通常メモ・シークレットメモ・サイドバーを閉じた状態の3つを確認する
- [ ] 文字と背景のコントラストが十分で、読みにくい箇所がないこと（特にサイドバーの文字、シークレットのサイドバー項目）
- [ ] 選択中のメモ、ホバー、フォーカス（検索欄・エディタ）の状態が見分けられること
- [ ] サイドバー幅 200px / 600px、ドラッグで幅を変えても崩れないこと
- [ ] 「☰」メニューと、ログの表示が読めること
- [ ] エディタの文字とハイライト層の位置がずれていないこと（余白・フォントの指定は触らない）

## 決定事項
- サイドバーは明るい単色にする。
- 削除・コピー・保存ボタンは、すべて無色の枠線ボタンにする（削除だけホバー時に赤）。
- シークレットメモはダーク配色のまま、装飾だけ簡素化する。
- 見た目だけを変え、HTML の構造・クラス名・挙動は変えない。

## 懸念点・未決事項
- サイドバーとメイン画面の境目が分かりにくくならないよう、細い線で区切る。実機で確認する。
- 明るいサイドバーにすると、シークレット項目（`.memo-item.secret`）の区別が弱くなる可能性がある。ダークグレーの背景で区別を保つかは実機で確認する。
- エディタの文字位置に関わる指定（フォント、余白、折り返し、スクロール）は、AGENTS.md の注意のとおり変更しない。
- 主操作（保存）が目立たなくなる。使いにくければ、保存だけ強調する案を後で検討する。
