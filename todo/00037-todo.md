# おばけ SVG を <symbol> で共通化する

## 概要
同じおばけ SVG が `src/memo.html`（2か所）と `src/memo.js`（一覧アイコン）にある。形を `<symbol id="ghost">` に1つだけ定義し、各所は `<use>` で参照する。線の太さ・色は CSS（`.secret-icon svg`）で一括指定する。

## 調査結果
- `src/memo.html:49`、`src/memo.html:59` に同じインライン SVG がある。
- `src/memo.js:18` の `SECRET_ICON` 定数が同じ SVG 文字列を持ち、`src/memo.js:133` で一覧に挿入する。
- `src/memo.css:152` の `.secret-icon svg` は幅・高さだけ指定している。
- 線の属性（`fill` / `stroke` / `stroke-width` / `stroke-linecap` / `stroke-linejoin`）は `<use>` 先へ継承されるので、CSS で `svg` に指定できる。

## 実装計画
- [x] ステップ1: `memo.html` の `<body>` 直後に、非表示の `<svg>` で `<symbol id="ghost" viewBox="0 0 64 64">` を定義する（`src/memo.html`）。
- [x] ステップ2: `memo.html` の2か所を `<svg aria-hidden="true"><use href="#ghost" /></svg>` に置き換える（`src/memo.html`）。
- [x] ステップ3: `memo.js` の `SECRET_ICON` を `<use>` 参照の短い文字列にする（`src/memo.js`）。
- [x] ステップ4: `.secret-icon svg` に `fill: none; stroke: currentColor; stroke-width: 3; stroke-linecap: round; stroke-linejoin: round;` を足す（`src/memo.css`）。
- [x] ステップ5: `AGENTS.md` の「おばけアイコン」の記述を `<symbol>` 参照に合わせる（`AGENTS.md`）。

## テスト・確認方法
- [x] `npm run check:quiet` を通す。
- [x] 実機で、一覧・ボタン・ラベルのおばけが表示され、`stroke-width` を変えると3か所が一緒に変わることを確認する（太さは 5 にした）。

## 決定事項
- 依頼どおり `<symbol>` 方式にする。
