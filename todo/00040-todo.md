# npm から pnpm への移行に伴うドキュメント・設定の更新

## 概要
パッケージ管理を npm から pnpm に移行したため、残っている npm 前提の記述・設定を pnpm に合わせる。

## 調査結果
- `package.json` は `packageManager: pnpm@12.23.0` 設定済み、`pnpm-lock.yaml` 生成済み、`package-lock.json` は削除済み
- npm 前提の記述が残る箇所:
  - `package.json` の `check:quiet`（`npm -s run`）
  - `README.md`（`npm install` とコマンド表の `npm test` など）
  - `AGENTS.md`（技術スタック、コマンド、バージョン記載の `package-lock.json`）
  - `.prettierignore`（`package-lock.json`）
- `.claude/skills` / `.opencode/skills` の npm 記述は汎用テンプレートの例なので対象外

## 実装計画
- [x] ステップ1: `package.json` の `check:quiet` を `pnpm -s run ...` に変更する
- [x] ステップ2: `README.md` のコマンドを pnpm に変更する
- [x] ステップ3: `AGENTS.md` の技術スタック・コマンド（`npx prettier` は `pnpm exec prettier`）・バージョン記載（`pnpm-lock.yaml` には本体の version がないので `package.json` だけにする）を更新する
- [x] ステップ4: `.prettierignore` の `package-lock.json` を `pnpm-lock.yaml` に変更する

## テスト・確認方法
- [x] `pnpm run check:quiet` が通る
- [ ] `pnpm exec prettier --check .` が通る（`src/settings.test.js` は今回の変更前から整形差分あり。範囲外）
- [x] `grep -rn "npm\|package-lock"` で対象ファイルに残りがない

## 決定事項
- 汎用スキルのテンプレート内の npm 記述は変更しない

## 懸念点・未決事項
- `src/settings.test.js` の Prettier 警告は移行と無関係の既存問題。範囲外のため未対応
