# ログの表示時間を設定できるようにする

## 概要
コピー・保存などで出る `.log-message` は、固定 3 秒で消える。表示時間を設定パネルで変えられるようにする。0 秒なら表示しない。

## 調査結果
- `src/memo.js` の `LOG_DISPLAY_MS = 3000`（18行）を `showLogMessage`（264行）の `setTimeout` で使っている
- 設定は `src/settings.js` の `Settings` / `DEFAULT_SETTINGS` / `loadSettings` / `clampNumber` で検証する。範囲定数（`FONT_SIZE_RANGE` など）を export している
- 設定パネルは `src/memo.html` の「表示」セクション（文字サイズ・タイトルの文字数）。`memo.js` の `showSettings` / `changeSettings` / `resetSettings` と、`change` イベント登録（750行付近）に項目を足す形
- 既存の入力は `select` だが、小数（0.3秒など）を自由に入れるため、このコードにはまだない `number` 入力が必要。`.settings-panel select` のスタイル（`src/memo.css` 473行付近）に合わせる
- `src/memo.test.js` の保存済み設定の期待値（50 / 888 / 910 / 1511行付近）に、新しい項目の追加が影響する

## 実装計画
- [x] ステップ1: `src/settings.js` に `LOG_DISPLAY_RANGE = { min: 0, max: 5000 }`（ms）と、`Settings.logDisplayMs`（既定 500）を追加する。`loadSettings` で `clampNumber` を使って検証する（旧データになければ 500）
- [x] ステップ2: `src/memo.html` の「表示」セクションに「ログの表示時間」の `<input type="number" class="log-display-input" min="0" max="5" step="0.1">` と「秒」の単位を追加する。0 のとき表示しないことが分かるよう、`title` かヒント文を付ける
- [x] ステップ3: `src/memo.css` で `.settings-panel input[type='number']` を、`select` と同じ余白・枠・文字サイズ・幅（60px 程度）にする。ミニマルな既存デザインに合わせ、色や影は足さない
- [x] ステップ4: `src/memo.js` の `LOG_DISPLAY_MS` を削除し、`settings.logDisplayMs` を使う。0 のときは `showLogMessage` で何も表示しない（前のログが残っていれば消す）。`showSettings` / `changeSettings` / `resetSettings` / `change` イベント登録に入力欄を追加する
  - 入力値は秒で扱い、保存時は `Math.round(秒 * 1000)` でミリ秒にする。範囲外・空欄は `clampNumber` と同様に 0〜5 秒に丸め、入力欄にも丸めた値を戻す
- [x] ステップ5: テストを追加・更新する（`src/settings.test.js`、`src/memo.test.js`）
- [x] ステップ6: `AGENTS.md` の設定の仕様に、ログ表示時間（0〜5秒・0.1秒刻み・既定0.5秒・0 は表示しない）を追記する

## 決定事項
- 範囲は 0〜5 秒、小数可（0.1 秒刻み）。0 は「表示しない」
- 既定は 0.5 秒（当初は現状どおり 3 秒だったが変更）
- 置き場所は設定パネルの「表示」セクション
- 通常・シークレットで分けず、共通の 1 項目にする（文字サイズ・タイトルの文字数と同じ扱い。ログは画面全体の表示のため）
- 0 秒のときは、エラー系も含めてすべてのログを表示しない
- 保存形式は `logDisplayMs`（ミリ秒）。他の時間の設定（`autoSaveDelayMs`）と単位をそろえる

## 懸念点・未決事項
- 0 秒にすると「保存しました」などの結果が一切見えなくなる。エラー系（「内容が空のため保存しませんでした」など）も出なくなる。表示しない対象を絞るかは未決（現計画ではすべて出さない）
- `number` 入力を初めて使うため、入力途中（空欄・範囲外）の挙動をテストで確認する
