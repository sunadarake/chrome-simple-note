# シークレットメモの操作ボタンを暗い背景でも見やすくする

## 概要
シークレットモード（`.main-content.secret`）のとき、タイトル行の削除・コピー・保存ボタンの文字色と枠色が暗い背景（`#2b2d31`）に埋もれて見えにくい。シークレットモードのときだけ、背景が黒でも判別しやすい明るい色に変える。通常メモ（ライト／ダークテーマ）は今のままにする。

## 調査結果
- ボタンは `src/memo.html:157-159` の `.delete-btn` / `.copy-btn` / `.save-btn`。`border: 1px solid` で色指定がないため、枠は `currentColor`（文字色と同じ）になる。
- 現在の色は `src/memo.css:662-684`。削除 `#e74c3c`、保存 `#27ae60`、コピー `#2980b9`。ホバー背景はそれぞれ淡い色（`#fdedec` / `#eafaf1` / `#eaf4fb`）。
- シークレットメモの背景は `src/memo.css:487-489` の `#2b2d31`。シークレット用の配色は同ファイル 472〜606 行にまとまっており、ハイライト色として `#f28b82`（赤系）・`#81c995`（緑系）・`#8ab4f8`（青系）を既に使っている。
- ダークテーマ（通常メモ）の配色は 704 行以降で `.main-content:not(.secret)` に限定されているため、シークレット用の追加ルールと競合しない。
- ログ（`.log-message`）は淡い背景のままなのでシークレットでも読める。今回は対象外。
- 色を参照するテストはない。

## 実装計画
- [x] ステップ1: `src/memo.css` のシークレット用スタイル（`.main-content.secret .md-italic` の後、ログのコメントの前）に、`.main-content.secret` の削除・保存・コピーボタンの文字色（＝枠色）を明るい色に上書きするルールを追加する。削除は `#f28b82`、保存は `#81c995`、コピーは `#8ab4f8`（既存のシークレット用ハイライト色と合わせる）。
- [x] ステップ2: 同じ場所に、シークレット時のホバー背景を各色の半透明（`rgba(..., 0.15)`）に上書きするルールを追加する。明るい文字色が淡い背景に埋もれないようにするため。
- [x] ステップ3: `npm test` / `npm run lint` / `npm run typecheck` を実行して通ることを確認する。

- [ ] 通常メモのボタンの色が変わっていないことを目視確認する

## 決定事項
- 変更対象はシークレットモード（`.main-content.secret`）のときだけ。通常メモ（ダークテーマを含む）は変更しない。
- 追加する色は既存のシークレット用ハイライト色（`#f28b82` / `#81c995` / `#8ab4f8`）に合わせ、配色の一貫性を保つ。
