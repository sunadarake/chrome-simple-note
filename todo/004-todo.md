# シークレットメモを見分けやすくする

## 概要
シークレットメモを開いているとき、一覧の項目とメイン画面の配色をダークグレー基調に変え、「シークレットメモ」と分かる表示も足す。
Chrome のシークレットウィンドウのように、色だけで通常メモと区別できるようにする。

## 調査結果
- `src/memo.js`: `renderMemoList` が一覧の項目を作り、`memo.secret` なら `🔒 ` を付けている。`loadMemo(id)` が選択したメモを表示する。選択中のメモは `currentId` で持つ
- `src/memo.html`: メイン画面は `.main-content` の中に `.title-display`、`.content-input`、`.footer` が並ぶ
- `src/memo.css`:
  - サイドバーは濃い青灰色（`#2c3e50`）、メイン画面は白背景。一覧の項目は `.memo-item`、選択中は `.memo-item.active`（青）
  - 「シークレットメモ」ボタン（`.secret-memo-btn`）は灰色のグラデーション（`#7f8c8d`〜`#566573`）
- 変更は `src/` の `memo.html` / `memo.css` / `memo.js` の範囲で済み、ストレージや `manifest.json` は触らない

## 実装計画
- [x] ステップ1: `memo.html` のメイン画面の先頭に、ラベル用の要素（`.secret-label`、既定は `hidden`）を追加する。文言は「🔒 シークレットメモ（タブを閉じると消えます）」（`src/memo.html`）
- [x] ステップ2: `memo.js` の `loadMemo` で、表示するメモが `secret` かどうかに応じて、`.main-content` の `secret` クラスの付け外しとラベルの表示切り替えを行う。メモを切り替えたとき、新規作成したとき、削除後に別のメモを開いたときも同じ処理を通る（`src/memo.js`）
- [x] ステップ3: `memo.js` の `renderMemoList` で、シークレットメモの項目に `secret` クラスを付ける。`🔒` は残す（`src/memo.js`）
- [x] ステップ4: `memo.css` に配色を追加する。`.memo-item.secret`（灰色寄りの背景。ホバー・選択中は `.memo-item.secret.active` で灰色系の左線に変え、通常メモの青と区別する）、`.main-content.secret`（暗い灰色の背景、タイトル・本文・フッターの文字と枠線を明るい色・暗い色に調整）、`.secret-label`（小さな帯状の表示）。色の値は既存の `secret-memo-btn` の灰色に合わせる（`src/memo.css`）
- [x] ステップ5: `AGENTS.md` の仕様・注意点に、シークレットメモを開いているときは `.main-content.secret` と一覧の `.memo-item.secret` で配色が変わる旨を簡潔に追記する（`AGENTS.md`）

## テスト・確認方法
- [x] `src/memo.test.js`: シークレットメモを開くと `.main-content` に `secret` クラスが付き、ラベルが表示される。通常メモを開くとクラスが外れラベルが隠れる。一覧のシークレットメモの項目に `secret` クラスが付く。メモを切り替えたとき（一覧のクリック、削除後）も正しく切り替わる
- [x] `npm run lint` / `npm run typecheck` / `npm test` / `npx prettier --check .` が通る
- [ ] `chrome://extensions` で読み込み、通常メモとシークレットメモを切り替えて、配色・ラベル・文字の読みやすさ（コントラスト）、選択中の項目の見分けやすさを目視で確認する（手動）

## 決定事項
- 変更する範囲は、一覧の項目とメイン画面の両方（開いている間はメイン画面全体の配色を変える）
- 配色はダークグレー基調。既存の「シークレットメモ」ボタンの灰色と合わせる
- メイン画面に「🔒 シークレットメモ（タブを閉じると消えます）」の表示を足す
- 一覧の `🔒` は残す（色だけに頼らない）

## 懸念点・未決事項
- 色の具体的な値と文字のコントラストは、実装後に画面で確認して調整する（JS のテストでは確認できない）
- `jsdom` は CSS の見た目を検証できないため、テストはクラスとラベルの表示切り替えまでを対象にする
- ラベルの位置（タイトルの上）と文言は暫定。実際の画面で、タイトルとの余白を見て調整する
- Chrome のダークモードやユーザーの OS 設定には連動させない（通常メモは今まで通り明るい配色のまま）
