# ダークモードを廃止する

## 概要
設定のテーマ項目（ライト／ダーク）と、通常メモのダークテーマ用の保存値・CSS を削除する。通常メモは常にライト配色にする。すでに `theme: 'dark'` が保存されている環境では、その値を無視してライト表示にし、次に設定を保存したときに `theme` キーごと消える。シークレットメモの暗い配色は残す。

## 調査結果
- `src/settings.js` の `Settings` 型・`DEFAULT_SETTINGS`・`loadSettings` が `theme` を持っている（`src/settings.js:16`、`src/settings.js:26`、`src/settings.js:117`）。
- `src/memo.html` の設定パネル「表示」にテーマの `select.theme-input` がある（`src/memo.html:168`）。
- `src/memo.js` が `themeInput` を取得し、`applySettings` で `.container` の `data-theme` を設定、`showSettings` / `changeSettings` / `resetSettings` と変更リスナーで `theme` を扱っている（`src/memo.js:101`、`src/memo.js:426`、`src/memo.js:443`、`src/memo.js:465`、`src/memo.js:485`、`src/memo.js:580`）。
- `src/memo.css` に `.container[data-theme='dark']` のダークテーマ用ルールがまとまっている（`src/memo.css:806` 以降）。また、シークレット用ルールとダーク用ルールが同じセレクタ群に並んでいる箇所がある（`src/memo.css:568` 以降）。
- `src/settings.test.js` と `src/memo.test.js` にテーマの既定値・変更・保存・リセットのテストがある（`src/settings.test.js:28`、`src/settings.test.js:42`、`src/memo.test.js:596` 以降）。
- `README.md` の機能表と `AGENTS.md` の設定・デザインの説明にテーマ（ライト／ダーク）が書かれている（`README.md:42`、`AGENTS.md:35`、`AGENTS.md:48`、`AGENTS.md:49`、`AGENTS.md:58`）。

## 実装計画
- [x] ステップ1: `src/settings.js` から `theme` の型・既定値・読み込みを削除する。古い保存値の `theme` は読み捨てる（`src/settings.js`）。
- [x] ステップ2: `src/memo.html` からテーマの設定行（`label.settings-row` と `select.theme-input`）を削除する（`src/memo.html:168`）。
- [x] ステップ3: `src/memo.js` から `themeInput` の取得、`container.dataset.theme` の設定、`showSettings` / `changeSettings` / `resetSettings` のテーマ処理、変更リスナーの登録を削除する。`container` は文字サイズの CSS 変数とショートカットの登録先で使うため残す（`src/memo.js`）。
- [x] ステップ4: `src/memo.css` からダークテーマ用のルールを削除する。`body:has(.container[data-theme='dark'])`、`.container[data-theme='dark']` の各ルール、およびシークレット用ルールと並んでいるダーク用セレクタを外す。`.main-content.secret` の配色と `.secret-label` は残す（`src/memo.css`）。
- [x] ステップ5: `src/settings.test.js` からテーマを前提にした値を外し、古い `theme: 'dark'` を読み込んでも既定値（テーマなし）になることを確認するテストに直す（`src/settings.test.js`）。
- [x] ステップ6: `src/memo.test.js` からテーマの表示・変更・保存・リセットのアサーションを削除し、`.container` に `data-theme` が付かないことを確認するテストに置き換える。カスタム設定の `theme` も外す（`src/memo.test.js`）。
- [x] ステップ7: `README.md` のテーマ行を削除し、`AGENTS.md` の設定項目・仕様・デザイン説明からテーマ／ダークテーマの記述を削除する。通常メモは常にライト配色であることを書き、シークレットメモの暗い配色は残す（`README.md`、`AGENTS.md`）。

## 決定事項
- ダークモード廃止の対象は、設定のテーマ機能・`Settings.theme`・`.container[data-theme='dark']` の CSS だけとする。シークレットメモの暗い配色は残す。
- 既存の `theme: 'dark'` は無視してライト表示にし、移行処理は入れない。次に設定を保存したときに `theme` キーが消える。

## 懸念点・未決事項
