# Ctrl+Shift+F で全メモ検索パネルを開く

## 概要
Ctrl+Shift+F で、全メモ（通常メモと、いま読み込まれているシークレットメモ）を横断検索する専用パネルを開く。結果には一致箇所の前後を切り出したスニペットを表示し、クリックでそのメモを開く。既存の Ctrl+F / Ctrl+P（一覧の絞り込み）はそのまま残す。

## 調査結果
- `src/shortcuts.js` に `SHORTCUTS`（ヘルプ表示）と `initShortcuts` の keydown 処理がまとまっている。Ctrl+F / Ctrl+P は `focusSearch` を呼ぶだけで、`shiftKey` を見ていない。
- `src/memo-store.js` の `filterMemos` がタイトルと本文を大文字小文字を区別せず検索する（通常・シークレットの両方を含む `memos` が対象）。
- `src/memo.js` に設定パネル / ヘルプパネルの開閉（`setSettingsOpen` / `setHelpOpen` / `closePanels` / `syncMainVisibility` / `handleEscape`）と、一覧の描画（`renderMemoList`）がある。パネルを開くと `editor.hidden` が true になり `isActive` が false になる。
- `src/memo.html` に `.settings-panel` / `.help-panel` があり、`src/memo.css` で `[hidden]` を `display: none` にしている。
- ヘルプのショートカット一覧は `SHORTCUTS` から描画され、`src/shortcuts.test.js` と `src/memo.test.js` でキー配列（現在12個）を検証している。
- README.md と AGENTS.md にショートカットとパネルの説明がある。

## 決定事項
- 全メモ検索は既存の一覧絞り込み（Ctrl+F）ではなく、専用パネルにする。
- 検索対象は通常メモと、いま読み込まれているシークレットメモの両方（現状の検索と同じ）。
- 一致箇所のハイライトは、色を増やさず下線で示す。
- パネルを開くたびに検索語を空にする（前回の検索語は残さない）。

## 懸念点・未決事項
- 1件のメモにつき最初に一致した箇所のスニペットだけを表示する（複数一致は出さない）。
- Enter で先頭の結果を開く操作は今回入れない（クリックのみ）。
- 一覧に検索パネルを開くボタンは置かず、ショートカットとヘルプの表記だけで案内する。
- 検索対象は保存済みのメモだけ（入力中で未保存の本文は、既存の一覧検索と同じく反映されない）。
