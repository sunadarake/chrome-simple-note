# メモを開いたときに本文欄へフォーカスする

## 概要
シークレットメモを開いたときに本文欄（`.content-input`）へフォーカスを当て、すぐ入力できるようにする。通常メモも同じようにフォーカスする。今はボタンや一覧をクリックしたあとフォーカスが本文欄に移らず、そのままでは入力できない。

## 調査結果
- `src/memo.js`: メモを表示する処理は `loadMemo(id)` に集約されている。起動時の `selectFirstMemoOrCreate`、一覧のクリック、`createNewMemo`、削除後の切り替えはすべて `loadMemo` を通る。
- `loadMemo` は本文の設定・ハイライト・タイトル表示の更新まで行うが、フォーカスは当てていない。
- `src/memo.html` の `.content-input` に `autofocus` はない。
- `src/memo.test.js`: 表示・切り替え・シークレットメモのテストがある。フォーカスを検証しているテストはない。

## 実装計画
- [x] ステップ1: `loadMemo` の最後で `contentInput.focus()` を呼び、表示したメモの本文欄にフォーカスを当てる（`src/memo.js`）
- [x] ステップ2: 起動時・一覧のクリック・シークレットメモの新規作成で本文欄にフォーカスが当たることをテストに追加する（`src/memo.test.js`）
- [x] ステップ3: `AGENTS.md` の仕様に、メモを開くと本文欄へフォーカスすることを追記する（`AGENTS.md`）

## テスト・確認方法
- [x] `npm test` が通る
- [x] `npm run lint` が通る
- [x] `npm run typecheck` が通る

## 決定事項
- フォーカスは `loadMemo` に集約し、起動時・一覧のクリック・新規作成・削除後の切り替えすべてで当てる。
