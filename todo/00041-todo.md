# シークレットラベルの背景色を #1e1e1e にする

## 概要
シークレットメモを開いている間に出る `.secret-label` の背景色を `#566573` から `#1e1e1e` に変える。

## 調査結果
- `src/memo.css` の `.secret-label`（671行付近）に `background: #566573; color: #ecf0f1;`
- 同じファイルの 182行付近にある `.secret-label { --ghost-eye: #566573; }` は、おばけの目をラベル背景に合わせる色。背景を変えると目だけ浮くので、同じ色にそろえる
- `.main-content.secret` の背景は `#2b2d31`（変更しない）。一覧の `.memo-item.secret.active` の青灰 `#566573` は別物なので変更しない
- `AGENTS.md` にはラベルの色の記述はなく、更新は不要
