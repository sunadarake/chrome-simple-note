最近の変更を調べて報告してください。範囲の指定: `$ARGUMENTS`

## 調べること
- 範囲の指定がなければ、最新のタグから現在まで(タグがなければ直近15件)を対象にする
- `git log --oneline` と `git diff --stat` で、変更の内容と規模を確認する
- コミットしていない変更があれば `git status --short` で確認する

## 報告内容(各項目は箇条書きで、全体で20行以内)
1. **追加**：新しく使えるようになったこと
2. **変更**：挙動や仕様が変わったこと(互換性がなくなるものは先頭に書く)
3. **修正**：直した不具合
4. **その他**：docs・リファクタ・chore など(1行にまとめる)
5. **未コミットの変更**：あればファイル名を挙げる

## ルール
- コミットメッセージの羅列ではなく、利用者から見て何が変わったかで書く
- 該当のない項目は省く。確認できていないことは推測せず「不明」と書く
- コードやファイルは変更しない
