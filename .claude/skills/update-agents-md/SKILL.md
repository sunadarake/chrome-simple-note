反映してほしい内容: $ARGUMENTS（空なら変更内容から判断）

## 現在の状態
!`git status --short`

## 変更概要
!`git diff HEAD --stat`

## 手順
1. 反映してほしい内容があれば、それを最優先で AGENTS.md に反映する。既存の記述と矛盾・重複しないか確認し、該当箇所だけ直す
2. 上記の概要を確認し、必要なら `git diff HEAD -- <ファイル>` で差分本文を見て、何が変わったかを把握する
3. `AGENTS.md` の記述が現在のコードと一致しているか確認し、必要な箇所だけ更新する
4. `AGENTS.md` を含む変更を `git add` し、`git commit -q` で1つのコミットにまとめる

## ログ
- 正常時は出力を小さくし、成功時の詳細は表示しない
- 失敗したときだけエラー内容を表示する

## AGENTS.mdのルール
- 反映してほしい内容にも、以下の「書くこと／書かないこと」を適用する
- 書くこと：今後の作業者（AI含む）が知らないと困る仕様、コマンド、ディレクトリ構成、規約、注意点
- 書かないこと：変更履歴や作業ログ、コードを読めばすぐ分かる細かい説明
- 古くなった記述は削除または修正する
- 既存の構成やトーンは維持し、差分は最小限にする
- 更新不要なら変更しない

## コミットメッセージ
- 日本語で簡潔かつ分かりやすく書く
- 1行目は50文字以内、prefix として feat/fix/refactor/docs/test/chore のいずれか
- 2行目は空行
- 3行目以降は「なぜ」を `- ` で始まる箇条書きで1〜3項目書く(1項目1行)
- `Co-Authored-By: Claude ...` や `🤖 Generated with Claude Code` などの署名・クレジット行は含めない

## 注意
- `.env`、認証情報、秘密鍵、ログや一時ファイルなど、コミットすべきでないものが含まれていたら、コミットせずに報告する
- 関係のない変更が混ざっている場合は、コミットを分けるか確認する
- push はしない

## 報告
完了後、AGENTS.mdの変更点（なければ「変更なし」）、コミットメッセージ、対象ファイルを簡潔に報告する
