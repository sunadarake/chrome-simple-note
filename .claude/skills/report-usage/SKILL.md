使い方を調べて説明してください。説明してほしい部分: `$ARGUMENTS`

## 調べること
- 指定がなければ、プロジェクト全体の使い方を対象にする
- 対象のファイル先頭のコメント、`-h` / `--help` の処理、README を読む
- 実際のコードで、引数・オプション・既定値・出力を確認する

## 報告内容(各項目は箇条書きで、全体で20行以内)
1. **何をするものか**：1〜2文
2. **基本の使い方**：コマンドの例を1つ
3. **主な引数・オプション**：名前と働きを一覧にする
4. **注意点**：ハマりやすいこと、前提条件(最大3項目)

## ルール
- README やコメントとコードの内容が食い違う場合は、コードを正として、食い違いを報告する
- 確認できていないことは推測せず「不明」と書く
- 説明の報告のみ行い、README は書き換えない(書き換えは `readme-update` の担当)
- コードやファイルは変更しない
