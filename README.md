# Simple Note

## 目的
Chrome のアイコンをクリックするだけで開ける、シンプルなメモ帳の拡張機能。
通常のメモに加えて、タブを閉じると消えるシークレットメモを書ける。

## セットアップ
```bash
git clone git@github.com:sunadarake/chrome-simple-note.git
cd chrome-simple-note
npm install   # テスト・lint などの開発用。拡張機能の実行には不要
```

Chrome で `chrome://extensions` を開き、「デベロッパーモード」を有効にして、「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選ぶ。

## 使い方
拡張機能のアイコンをクリックすると、メモ画面のタブが開く。既に開いているときは、そのタブに切り替わる。

- 「＋ 新しいメモ」で通常のメモを作る。`localStorage` に保存される
- 「シークレットメモ」ボタンでシークレットメモを作る。`sessionStorage` に保存され、タブを閉じると消える
- メモを開くと本文欄にフォーカスが当たり、すぐ入力できる
- 「保存」ボタンで保存する。設定で自動保存をオンにすると、入力が止まったあとに自動で保存される（通常メモ・シークレットメモで別々に設定でき、既定はオフ・1 秒）。「コピー」「削除」のボタンもある
- サイドバー左上の3本線から、設定パネルを開く
- サイドバーの「?」から、ショートカット一覧とバージョンを表示するヘルプを開く
- メモ画面では Ctrl+C（コピー）、Ctrl+S（保存）、Ctrl+Z（本文のアンドゥ）、Ctrl+Shift+Z（リドゥ）、Ctrl+O（新しいメモ）、Ctrl+Shift+O（シークレットメモ）、Ctrl+F / Ctrl+P（検索欄へフォーカス）、Ctrl+Shift+F（全メモ検索）、Ctrl+J / Ctrl+K（前後のメモ）、Ctrl+,（設定）、Esc（パネルやタイトル編集を閉じる）、Delete（メモ削除）のキーボードショートカットが使える

## 仕様

| 機能 | 説明 |
|:-|:-|
| メモ一覧 | 本文の最初の1行（前後の空白と先頭の `#` は除く）の先頭 50 文字（設定で 10〜100 文字）をタイトルとして表示する。タイトルをクリックすると手動で変更でき、空にすると本文の1行目に戻る |
| 検索 | タイトルと本文を対象に、大文字小文字を区別せず絞り込む。Ctrl+Shift+F では、通常メモと読み込まれているシークレットメモを横断検索し、一致箇所の前後をスニペット付きで並べるパネルを開く。結果をクリックするとそのメモを開く |
| 設定パネル | サイドバー左上の3本線で開く。開いている間はエディタの代わりに表示される。変更はすぐ画面に反映され、「設定を保存」で保存する。「デフォルトに戻す」は確認してから全項目を既定値に戻して保存する |
| ヘルプ | サイドバーの「?」で開く。ショートカット一覧と、いまの拡張機能のバージョンを表示する。設定パネル・全メモ検索とは同時に開かない |
| エクスポート／インポート | 設定パネルから、通常メモを JSON ファイルに書き出し、読み込む。インポートはパネルへのドラッグ＆ドロップ（複数可）でもできる。今あるメモに追加し、同じ ID はスキップし、並び順は維持される |
| 自動保存 | 通常メモ・シークレットメモそれぞれで、既定はオフ。オン／オフと、保存までの時間（0.5〜5 秒）を設定できる。オフのときは「保存」ボタンだけで保存する |
| 削除の確認 | 通常メモ・シークレットメモそれぞれで、削除前に確認するかを設定できる。既定はどちらも確認する。全メモ削除は設定に関係なく常に確認する |
| ショートカット | Ctrl+C（選択がなければ本文全体をコピー）、Ctrl+S（保存）、Ctrl+Z（本文のアンドゥ）、Ctrl+Shift+Z（リドゥ）、Ctrl+O（新しいメモ）、Ctrl+Shift+O（シークレットメモ）、Ctrl+F / Ctrl+P（検索欄へフォーカス）、Ctrl+Shift+F（全メモ検索）、Ctrl+J / Ctrl+K（前後のメモ）、Ctrl+,（設定）、Esc（パネルやタイトル編集を閉じる）、Delete（メモ削除）。エディタを表示している間だけ効き、設定・ヘルプ・全メモ検索を開いている間は Esc 以外は無効 |
| アンドゥ／リドゥ | Ctrl+Z で本文を1つ前の状態に戻し、Ctrl+Shift+Z でやり直す。多段で戻せ、メモを切り替えると履歴は消える。対象は本文だけで、手動タイトルは戻らない |
| 文字サイズ | エディタの文字サイズを 12〜24px で変えられる |
| タイトルの文字数 | 一覧のタイトルにする本文の文字数を 10〜100 で変えられる。変えると保存済みのメモにも反映される。手動で付けたタイトルも同じ文字数で表示を切る |
| 全メモ削除 | 通常メモをすべて削除する。シークレットメモは残る |
| 空のメモ | 本文もタイトルも空（空白のみを含む）のメモは保存しない。本文が空でも手動タイトルがあれば保存する |
| ハイライト | 見出し・太字・斜体・コード・リスト・引用・リンク・区切り線を、エディタ上で色分けする。コードブロックの中も、コメント・文字列・数値・キーワードを色分けする |
| サイドバーの開閉 | 「SimpleNote」の横のボタンで閉じ、閉じている間は左上のボタンで開く。状態は次回も保持される |
| サイドバーの幅 | 境界をドラッグして 200〜600px の間で変えられ、次回も保持される |
| シークレットメモ | 一覧におばけのアイコンが付き、開いている間はダークグレーの配色になる。操作ボタンは暗い背景でも見える明るい色になる |

| コマンド | 説明 |
|:-|:-|
| `npm test` | テストを実行する |
| `npm run lint` | ESLint を実行する |
| `npm run typecheck` | 型チェックを実行する |
| `npm run check:quiet` | テスト・lint・型チェックを順に実行する。成功時は1行、失敗時は全出力を表示する |
| `npm run format` | Prettier で整形する |
| `./build_for_test.sh` | 動作確認用に zip を `release/` に作る |
| `./publish.sh` | zip を作って GitHub Release に公開する。公開後、古い Release とタグを自動で削除する |
