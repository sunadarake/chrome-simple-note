# Simple Note

## 目的
Chrome のアイコンをクリックするだけで開ける、シンプルなメモ帳の拡張機能。
通常のメモに加えて、タブを閉じると消えるシークレットメモを書ける。

## セットアップ
```bash
git clone git@github.com:sunadarake/chrome-simple-note.git
cd chrome-simple-note
npm install   # テスト・lint などの開発用。拡張機能の実行には不要
```

Chrome で `chrome://extensions` を開き、「デベロッパーモード」を有効にして、「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選ぶ。

## 使い方
拡張機能のアイコンをクリックすると、新しいタブでメモ画面が開く。

- 「＋ 新しいメモ」で通常のメモを作る。`localStorage` に保存される
- 「🔒 シークレットメモ」でシークレットメモを作る。`sessionStorage` に保存され、タブを閉じると消える
- 入力が止まると自動保存される（既定は 1 秒）。「保存」「コピー」「削除」のボタンもある
- サイドバー左上の歯車から、設定パネルを開く

## 仕様

| 機能 | 説明 |
|:-|:-|
| メモ一覧 | 本文の最初の1行（先頭の `#` は除く）の先頭 30 文字（設定で 10〜100 文字）をタイトルとして表示する |
| 検索 | タイトルと本文を対象に、大文字小文字を区別せず絞り込む |
| 設定パネル | サイドバー左上の歯車で開く。開いている間はエディタの代わりに表示される |
| エクスポート／インポート | 設定パネルから、通常メモを JSON ファイルに書き出し、読み込む。インポートは設定パネルへのドラッグ＆ドロップ（複数可）でもでき、追加で、同じ ID はスキップし、並び順は維持される |
| 自動保存 | オン／オフと、保存までの時間（0.5〜5 秒）を設定できる。オフのときは「保存」ボタンだけで保存する |
| 文字サイズ | エディタの文字サイズを 12〜24px で変えられる |
| タイトルの文字数 | 一覧のタイトルにする本文の文字数を 10〜100 で変えられる。変えると保存済みのメモにも反映される |
| テーマ | ライト／ダークを切り替えられる |
| 全メモ削除 | 通常メモをすべて削除する。シークレットメモは残る |
| 空のメモ | 何も書いていない（空白のみを含む）メモは保存しない |
| ハイライト | 見出し・太字・斜体・コード・リスト・引用・リンク・区切り線を、エディタ上で色分けする |
| サイドバーの開閉 | 「SimpleNote」の横のボタンで閉じ、閉じている間は左上のボタンで開く。状態は次回も保持される |
| サイドバーの幅 | 境界をドラッグして 200〜600px の間で変えられ、次回も保持される |
| シークレットメモ | 一覧に 🔒 が付き、開いている間はダークグレーの配色になる |

| コマンド | 説明 |
|:-|:-|
| `npm test` | テストを実行する |
| `npm run lint` | ESLint を実行する |
| `npm run typecheck` | 型チェックを実行する |
| `npm run format` | Prettier で整形する |
| `./release.sh` | 配布用の zip を `release/` に作る |
| `./publish.sh` | zip を GitHub Release に公開する |
